# IBTech — Cloud Infrastructure Capability Statement

## Overview

IBTech delivers cloud and hybrid-infrastructure services covering migration,
operation, and optimization. Our engineers operate production environments that
combine on-premises data centers with public cloud, with proven experience in
high-availability and disaster-recovery designs for mission-critical government
workloads.

## Core Competencies

- **Cloud platforms** — Oracle Cloud Infrastructure (OCI) and Microsoft Azure,
  including landing-zone design, networking, and security baselines.
- **Hybrid and virtualization** — Nutanix hyper-converged infrastructure and
  Microsoft virtualization, integrated with cloud services for burst and DR.
- **Cloud migration** — assessment, planning, and phased migration of workloads
  with minimal disruption to live services.
- **Infrastructure as Code** — repeatable provisioning with Terraform and
  configuration management for consistent environments.
- **High availability and disaster recovery** — primary and secondary data
  center designs, backup and restore validation, and periodic DR testing to
  meet availability targets of 99%–99.5% per service tower.
- **Cloud security** — identity and access management, network segmentation,
  vulnerability management, and compliance controls.

## Representative Engagements

- **Jouf University — IT Managed Services.** Operates a hybrid environment
  spanning a primary data center and a disaster-recovery site, Nutanix-based
  virtualization, Oracle databases, and integration with Oracle Cloud
  Infrastructure (OCI), under a 24/7 operating model.
- **Government operations centers.** Designed and maintained resilient
  infrastructure for unified operations environments requiring continuous
  availability.

## Technology Stack

Oracle Cloud Infrastructure (OCI), Microsoft Azure, Nutanix, Microsoft Active
Directory, Oracle Database and Data Guard, Terraform, and enterprise backup and
storage platforms.

## Standards and Governance

Cloud operations follow the firm's ITIL-aligned service-management model —
incident, change, release, and configuration management — with executive
dashboards, SLA tracking, and continuous-improvement reviews.
